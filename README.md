# Codex Cyber Skills

Reusable cyber workflow skills for authorized security research.

A plugin intended to maximize the cyber capabilities of Codex, intended for verified members of the Trusted Access for Cyber (TAC) program. Verified members are granted access to more lax models with less cyber guardrails. 

Use this plugin to:
- Model security boundaries of a target
- Uncover code vulnerabilities in codebases
- Disassemble and decompile binaries
- Debug binaries and apps during runtime
- Inspect live web and mobile applications
- Access latest CVEs and attack vectors
- Build custom fuzzers and test harnesses
- Proof attack vectors and exploit chains

Common users (all TAC verified):
- Researchers protecting their own software
- HackerOne / Bugcrowd bounty hunters
- Apple / Google / Microsoft / Meta / other commercial bounty hunters

To avoid account usage violations:
- **Do not use this plugin with non-TAC accounts.**
- **Only use this plugin on authorized targets.**
